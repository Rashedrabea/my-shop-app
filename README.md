# 🏆 نظام راشد المحاسبي (Rashed ERP V20)

![Version](https://img.shields.io/badge/version-20.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

**نظام محاسبي وتجاري متكامل (ERP) يعمل بالكامل على المتصفح والموبايل.**
تم بناء هذا النظام ليكون حلًا بسيطًا وقويًا لأصحاب الشركات والمحلات الصغيرة والمتوسطة لإدارة مبيعاتهم، مشترياتهم، مخزونهم، وخزنتهم بدقة وسهولة.

---

## ✨ المميزات الرئيسية

*   **📊 لوحة تحكم (Dashboard):** واجهة مربعات تفاعلية تسمح بالوصول السريع لجميع الأقسام.
*   **🛒 المبيعات والمشتريات:** تسجيل فواتير البيع والشراء مع نظام "آجل" (ديون) و "كاش".
*   **📦 إدارة المخزون:** تتبع دقيق للكميات، مع خصم تلقائي عند البيع، وإضافة تلقائية عند الشراء.
*   **💰 الخزنة (Treasury):** نظام مالي متكامل يسجل كل الأموال الداخلة والخارجة (بيع، شراء، إيداع، سحب).
*   **🤖 البحث الذكي (Smart Search):** اكتب أول حرف فقط وستظهر لك النتائج فوراً من قوائم العملاء والموردين.
*   **🔢 الترقيم التلقائي:** رقم فاتورة متسلسل وتلقائي (`INV-0001`, `INV-0002`...).
*   **📑 التقارير المحاسبية:** تقارير دقيقة تشمل (ميزان المراجعة، قائمة الدخل، الميزانية العمومية، وكشف حساب العملاء).
*   **☁️ المزامنة السحابية (Firebase):** احفظ بياناتك في السحابة للوصول إليها من أي جهاز.
*   **📱 تصميم متجاوب:** يعمل بشكل مثالي على الموبايل، التابلت، والكمبيوتر.

---

## 🛠️ التقنيات المستخدمة

*   **HTML5 & CSS3:** لبناء الهيكل والتصميم الجذاب.
*   **JavaScript (Vanilla):** للمنطق البرمجي والتفاعلات (بدون أي تعقيدات).
*   **Chart.js:** للرسوم البيانية التفاعلية.
*   **Firebase:** للتخزين السحابي والمزامنة الآمنة.

---

## 🚀 كيفية التشغيل (للمطورين)

هذا المشروع يعتمد على ملفات بسيطة. يمكنك تشغيله مباشرة دون الحاجة لأي بيئات تطوير معقدة.

1.  قم بتحميل الملفات الثلاثة:
    *   `index.html`
    *   `style.css`
    *   `script.js`
2.  ضع الملفات في نفس المجلد.
3.  افتح ملف `index.html` باستخدام أي متصفح ويب حديث (Chrome, Edge, Firefox).
4.  قم بتسجيل الدخول باستخدام البيانات الافتراضية:
    *   **اسم المستخدم:** `admin`
    *   **كلمة المرور:** `123456`

*(ملاحظة: يمكن تغيير بيانات الدخول من داخل ملف `script.js`).*
